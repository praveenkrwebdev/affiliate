# The Organized Home

Static GitHub Pages starter site for the Organized Home project.

## Included
- Responsive editorial-style homepage
- 6 category pages
- 10 article pages
- Articles index
- About / Contact / Privacy / Terms / Affiliate Disclosure
- Custom 404 page
- Client-side search
- robots.txt + sitemap.xml
- WebSite/Article/Breadcrumb schema placeholders can be added as content is finalized
- No framework or build step

## Before publishing
1. Replace `praveenkrwebdev/affiliate` in `robots.txt` and `sitemap.xml`.
2. Replace the placeholder contact email in `contact/index.html`.
3. Review legal pages for the actual owner, jurisdiction, analytics and affiliate programs.
4. Add final owned image assets rather than relying on external image URLs.
5. Add page-specific canonical, Open Graph and JSON-LD metadata using the final GitHub Pages URL.
6. When a custom domain is ready, update canonical URLs, sitemap, robots and internal absolute references.

## GitHub Pages
Upload the contents of this folder to the repository root (or the intended Pages branch/folder), then enable GitHub Pages.

## Important
This is a launch-ready design/content foundation, not legal advice and not a final monetization configuration.
